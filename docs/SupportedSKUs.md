# Azure VM SKUs that Support AziHSM

Azure Integrated HSM is currently available to use on the AMD v7 generally available platform in all regions that support AMD v7.
Specifically, the VM SKUs that have 8+ vCores in the following series are supported:

* [Dasv7 series](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/general-purpose/dasv7-series)
* [Dadsv7 series](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/general-purpose/dadsv7-series)
* [Easv7 series](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/memory-optimized/easv7-series)
* [Eadsv7 series](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/memory-optimized/eadsv7-series)

**Please note:** Only the VM SKUs in these series that have *8+ vCores* support AziHSM.
